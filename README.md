# Portfólio Gabriel - Desenvolvedor Fullstack

Um portfólio moderno e responsivo desenvolvido com React, TypeScript e Tailwind CSS.

## 🚀 Características

- **Design Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Tema Claro/Escuro**: Alternância entre modos claro e escuro
- **Multilíngue**: Suporte para Português e Inglês
- **Animações Suaves**: Transições e animações com Framer Motion
- **Componentes Modernos**: Interface limpa e profissional

## 🛠️ Tecnologias Utilizadas

- **React** com TypeScript
- **Tailwind CSS** para estilização
- **React Context** para gerenciamento de estado

## 📱 Seções do Portfólio

1. **Hero**: Apresentação principal com call-to-action
2. **Sobre**: Informações pessoais e experiência profissional
3. **Habilidades**: Tecnologias e ferramentas dominadas
5. **Contato**: Formulário de contato e informações

## 🎨 Funcionalidades

- ✅ Navegação suave entre seções
- ✅ Toggle de tema claro/escuro
- ✅ Alternância de idioma (PT/EN)
- ✅ Formulário de contato funcional
- ✅ Links para redes sociais
- ✅ Design totalmente responsivo
- ✅ Animações e transições suaves

## 🚀 Como Executar

1. Clone o repositório
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Execute o projeto:
   ```bash
   npm start
   ```
4. Acesse `http://localhost:3000`

## 📦 Scripts Disponíveis

- `npm start` - Executa o projeto em modo de desenvolvimento
- `npm run build` - Cria build de produção
- `npm test` - Executa os testes
- `npm run eject` - Ejecta a configuração do Create React App
